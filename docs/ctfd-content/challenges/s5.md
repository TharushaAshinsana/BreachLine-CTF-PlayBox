You have recovered a **synthetic forensic filesystem image** from a compromised NovaTech server.

#### Your tasks
1) Download the evidence image (server_image.dd) and **do not modify it**.
2) Correlate evidence sources inside the image:

4) Extract the recovered content and locate the **flag**.

- If provided, verify integrity using the accompanying SHA256 file.
