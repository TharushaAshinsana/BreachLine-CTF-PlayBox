### NovaTech Incident Evidence — The Exfiltration Tool (S6)

During the investigation, an **ELF executable** suspected to be the attacker’s exfiltration tool was recovered.

#### Your tasks
1) Download the ELF binary (exfil_tool.elf).
2) Perform **basic static analysis** to understand how it validates input.
3) Determine the correct input value and execute the program.
4) When provided the correct input, the tool will output the **flag**.

#### Notes
- Run the binary in a **safe local VM/lab environment**.
- If a SHA256 file is provided, verify integrity before analysis.
